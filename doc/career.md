## 템플릿

```
### 프로젝트명

- 소속사 :
- 기간 : YYYY.MM ~ YYYY.MM (총 N개월)
- 역할 : (예: 퍼블리싱PL, 팀장 등)
- 투입 인원 : 총 N명 (본인 역할 비중: 직접 구현 / 관리·검수 등)
- 구현 범위 : (web pc/mobile, app, responsive 등)
- 사용 기술 : (html, scss, javascript/jquery, react, typescript 등)
- 웹접근성 인증 : (여부, 해당 시 인증 등급)
- 사이트 URL : (공개 가능 시 / 비공개면 스크린샷·영상으로 대체)
- 담당 업무 : (본인이 "주도"한 일 위주로 — 참여 수준 말고 실제 역할)
  - (예: 퍼블리싱 코드 컨벤션 및 컴포넌트 구조 수립, 팀원 코드리뷰)
  - (예: 일정/리소스 관리, 고객사와 화면 요건 협의)
  - (예: 신입/팀원 교육, 기술 가이드 문서 작성)
- 트러블슈팅 : (문제 상황 → 원인 → 해결 방법 → 결과 순으로)
  - (예: 레거시 코드와 신규 개발 영역 혼재로 배포 충돌 발생 → 빌드 단계를 모듈별로 분리하고 배포 스크립트 재설계 → 배포 안정성 확보)
- 성과 : (가능하면 수치로)
  - (예: 수동 배포 프로세스 자동화로 배포 소요 시간 OO% 단축)
  - (예: 공통 컴포넌트 가이드 수립으로 팀원 간 코드 편차 감소)
```
